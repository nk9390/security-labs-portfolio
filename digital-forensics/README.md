# Digital Forensics Labs

| Lab | Topic | Tools |
|---|---|---|
| [Lab 1](lab1.pdf) | Investigation of the `Mantooth.E01` disk image: OS and file system identification, user accounts, deleted executables, document metadata, media review | Autopsy |
| [Lab 2](lab2.pdf) | FTK Imager: forensic imaging, supported formats, hash verification, preview vs acquire | FTK Imager |
| [Lab 3](lab3.pdf) | Network analysis: HTTP and DNS filtering, TCP three-way handshake | Wireshark |
| [Lab 4](lab4.pdf) | Image analysis: deleted files, users, clusters, boot sector, report generation | ProDiscover |
| [Lab 5](lab5.pdf) | Email forensics: .eml acquisition and header analysis | Aid4Mail, MXToolbox |

Lab 6 (Windows Registry) is not included here.
