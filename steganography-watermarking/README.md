# Image-Based Data Hiding: LSB, DCT and DWT with Python

Team project (3 members) for the Digital Watermarking and Steganography course at VIT. [Read the report](project-report.pdf).

**Scope:** literature review and a comparative evaluation of LSB, DCT, DWT and a proposed hybrid, judged on PSNR, MSE, embedding time and capacity.

**Reported results (512x512 cover image):** PSNR of 43.7 dB (LSB), 48.5 dB (DCT), 50.1 dB (DWT) and 54.2 dB (hybrid).
