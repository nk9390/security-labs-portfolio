# Team course report: LSB, DCT and DWT image data hiding

Group project (3 members: Karthikey Nori, Megh Mehta, JebinSkaran) for the Digital Watermarking and Steganography course at VIT, supervised by Dr Jenika S. [Read the report](project-report.pdf).

It compares LSB, DCT, DWT and a proposed hybrid on PSNR, MSE, embedding time and capacity (reported PSNR 43.7 to 54.2 dB on a 512x512 image).

My own follow-up, with keyed embedding, error correction and attack testing, is in [`../../image-watermarking-robustness/`](../../image-watermarking-robustness/).
